## 📌 About The Project

**Online Attendance System** is a web-based attendance management application developed to make the process of recording and managing student attendance faster, easier, and more organized.

The system replaces traditional paper-based attendance with a digital solution where authorized users can manage students, mark attendance, view attendance records, and generate useful reports.

It is suitable for **schools, colleges, coaching institutes, and other educational organizations**.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 🔐 **Secure Login** | Authentication for authorized users |
| 👨‍🎓 **Student Management** | Add, update and manage student information |
| 📝 **Attendance Marking** | Mark student attendance digitally |
| 📅 **Date-wise Records** | View attendance based on specific dates |
| 📊 **Attendance Reports** | Easily monitor attendance records |
| 🔍 **Search System** | Quickly find student information |
| 🗂️ **Digital Records** | Maintain organized attendance data |
| 💻 **User-Friendly UI** | Simple and easy-to-use interface |

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/rajendrasahu82645-bit/Online-Attendance-System.git
```

## 2️⃣ Open XAMPP

Start the following services:

```text
Apache
MySQL
```

## 3️⃣ Move Project to htdocs

Copy the project folder into:

```text
C:\xampp\htdocs\
```

## 4️⃣ Create Database

Open:

```text
http://localhost/phpmyadmin
```

Create a new database and import:

```text
database.sql
```

## 5️⃣ Configure Database

Update your PHP database connection according to your MySQL configuration.

Example:

```php
$host = "localhost";
$username = "root";
$password = "";
$database = "attendance_system";
```

## 6️⃣ Run the Application

Open your browser and visit:

```text
http://localhost/Online-Attendance-System/
```
